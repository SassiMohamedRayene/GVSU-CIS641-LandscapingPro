## Project Overview

LandscapingPro is a web application I am developing for a landscaping
company. It will help customers explore services, submit quote requests,
and view appointment information.

The business owner will use a private dashboard to review requests,
prepare prices, and manage appointments. The goal is to keep customer
information and service requests organized in one place.

## Main Features

- Browse landscaping services.
- Submit quote requests with property and project details.
- Review and respond to quotes.
- View scheduled appointments.
- Manage services, customers, quotes, and jobs.

## Planned Technologies

- React
- ASP.NET Core Web API and C#
- Entity Framework Core
- SQL Server
